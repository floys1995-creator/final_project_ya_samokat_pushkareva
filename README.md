# Автотесты для API Яндекс Самокат

## Описание проекта

Данный проект содержит автоматизированный тест для API-эндпоинтов сервиса Яндекс Самокат.

### Тестируемый сценарий:
1. Создание заказа (`POST /api/v1/orders`)
2. Получение заказа по треку (`GET /api/v1/orders/track`)

### Шаги автотеста:
1. Выполнить запрос на создание заказа.
2. Сохранить номер трека заказа.
3. Выполнить запрос на получение заказа по треку заказа.
4. Проверить, что код ответа равен 200.

## Структура проекта

- `configuration.py` - конфигурационные параметры (URL, пути API)
- `data.py` - тестовые данные
- `sender_stand_request.py` - функции для отправки запросов к API
- `create_order_test.py` - тест-кейс
- `README.md` - документация проекта
- `.gitignore` - игнорируемые файлы

## Требования

- Python 3.8+
- pytest 7.0+
- requests 2.28+
